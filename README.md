# System Design Made Simple

Beginner-to-advanced system design notes with plain-language explanations and Mermaid diagrams.

Covers the classic interview curriculum — foundations, building blocks, and design problems — rewritten for learning (not a copy of any single book or notes repo).

## Topics

**Foundations**
- Scale from zero to millions
- Back-of-the-envelope estimation
- Interview framework

**Building blocks**
- Rate limiter, consistent hashing, key-value store, unique ID generator

**Design problems**
- URL shortener through stock exchange (28 lessons total)

## Run locally

```bash
npm install
npm run dev -- --port 43123
```

Open [http://127.0.0.1:43123](http://127.0.0.1:43123).

## Stack

- Next.js (App Router) + TypeScript + Tailwind CSS
- Markdown lessons in `/content`
- Mermaid diagrams rendered in the browser

## Learn path

Open the home page and follow lessons in order, or jump from the sidebar.
